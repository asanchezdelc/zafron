# Zafron

A rudimentary simple dashboard for devices such as Arduinos, ESP family, RaspberryPi, LoRaWAN, HTTP and more. This project was brought to life due to Cayenne EOL. It uses the Cayenne MQTT protocol to send data to the server. 

[Documentation](https://zafron.dev/docs/intro)

Get started quickly using [Zafron Cloud](https://zafron.dev)
